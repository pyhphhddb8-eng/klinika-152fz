# Комплект 152-ФЗ для сайта с онлайн-записью

Демо-сайт вымышленной клиники: страница записи на приём с правильно
устроенной формой и три документа отдельными страницами.

Четвёртая из семи новых работ для портфолио профиля FL.ru `kusaka63`.

Читать `docs/superpowers/specs/2026-09-14-klinika-152fz-design.md` — там

## Текущее состояние

Сайт собран: страница записи на приём, три страницы документов
(`privacy.html`, `consent.html`, `terms.html`), общий подвал с реквизитами,
уведомление о единственной технической записи, которую сайт хранит в
браузере, и форма с непредзаполненной галочкой согласия, которая реально
блокирует отправку без неё.

Собирается командой `npm run build` (Python-скрипт `build.py`, подставляет
реквизиты из `content/site.json` в шаблон и документы). Проверяется
командой `npm test` (сборка и содержимое страниц) и командой `npm run check`
(Playwright: контраст, отсутствие горизонтальной прокрутки на 360 px,
рабочие ссылки, печатный режим, чистая консоль). Скриншоты страниц —
командой `npm run shot`, результат в `tools/shots/`.

Живого адреса пока нет — сайт не выложен.

Реквизиты клиники (название, ИНН, ОГРН, адрес, телефон, почта и другие
подставляемые значения) правятся только в одном месте — файле
`content/site.json`; вручную по страницам и документам их искать не нужно.

## Две границы, проведённые до начала

**Форма не собирает данные о здоровье.** Имя, телефон, услуга, удобное время
— и всё. Как только появляется поле про жалобу или симптом, это специальная
категория персональных данных со своими требованиями. Самый полезный совет
клинике — не спрашивать на сайте то, что спросят на приёме.

**Информированное согласие на медицинское вмешательство в комплект не
входит.** Это 323-ФЗ, подписывается в клинике, к сайту отношения не имеет.

## Что работа показывает

Не тексты — они типовые. Показывает четыре решения, которые обычно делают
неправильно: непредзаполненная галочка, которая действительно блокирует
отправку; отсутствие лишних полей в форме; ответ на вопрос, куда физически
падают заявки; реквизиты в подвале.

## Чего мы не делаем

Не берём реквизиты реальной компании. Не подаём уведомление в Роскомнадзор за
клиента и не заходим в его кабинет на Госуслугах. Не обещаем, что после
работы не будет штрафа. И прямо пишем на страницах, что это типовой комплект,
а не юридическая консультация.
